# 유출장부

유출장부는 개인정보 유출 알림을 기록하고, 위험 정도를 확인한 뒤 할 일을 하나씩 직접 해 보며 끝내는 앱입니다. 유출된 정보로 어떤 일이 생길 수 있는지도 체험해 봅니다.

고색고 응용 프로그래밍 개발 개인 프로젝트(수행평가 4차)로 만들었습니다.

## 배포 주소

https://reisi09-school-assignment-leak-ledgerapp-leak-ledger-jeudp4.streamlit.app/

## 화면 안내

| 화면 | 하는 일 |
| --- | --- |
| 소개 | 앱의 사용 방법과 해 주는 일을 안내합니다. 기록하기, 실제 사례, 체험하기로 시작합니다. |
| 기록하기 | 받은 유출 알림 문자·메일을 붙여넣으면 유출된 정보를 찾아 골라 줍니다. 직접 적거나 실제 사례를 골라 기록할 수도 있습니다. 위험 점수를 매기는 기준도 확인합니다. |
| 할 일 | 기록마다 카드가 있고, 카드 위쪽 계기판이 남은 위험 점수를 보여 줍니다. 할 일마다 [시작하기]를 누르면 해 보기 창이 열립니다. 끝내면 그 할 일이 막는 공격에 '막은 공격' 표시가 붙고, 계기판 바늘이 내려가며, 화면 구석에 알림이 뜹니다. 끝낸 할 일은 [결과 보기]로 결과를 보고 남은 일로 되돌릴 수 있습니다. 한 기록의 할 일을 모두 끝내면 축하 표시가 나옵니다. 카드에는 서비스 분류와 메모도 보입니다. 서비스 이름으로 검색하고 전체 / 아직 남음 / 다 끝냄으로 골라 봅니다. 같은 정보가 두 곳 이상에서 유출되면 알려 줍니다. 기록 고치기·지우기와 이미 퍼진 비밀번호 확인도 할 수 있습니다. |
| 통계 | 기록 수, 남은 위험 점수 합계, 끝낸 할 일 비율을 큰 숫자로 보여 줍니다. 위험 등급별 기록 수와 많이 유출된 정보를 막대그래프로 보여 줍니다. 사칭 문자 가려내기의 최고 점수도 확인합니다. |
| 체험하기 | 해커 시점 체험과 사칭 문자 가려내기 두 가지가 있습니다. 해커 시점 체험은 정보를 누르면 위험 점수가 바로 바뀌고 그 정보로 공격자가 할 수 있는 일이 나타납니다. 사칭 문자 가려내기는 문자 예시 8개를 보고 진짜 안내인지 사칭인지 고릅니다. 내 기록에서 유출된 정보와 관련된 문제가 먼저 나옵니다. |

### 할 일을 직접 해 보는 창

유출된 정보에 따라 필요한 할 일이 나옵니다. 아래의 공격 이름은 앱에서 붙이는 표시입니다. 그 기록의 유출 정보로 가능한 공격만 표시하며, 실제 공격을 막았는지 확인한 결과는 아닙니다.

| 할 일 | 창에서 하는 일 | 끝내면 막는 공격 |
| --- | --- | --- |
| 비밀번호 바꾸기 | 연습용 새 비밀번호를 넣고 한국인터넷진흥원 기준의 문자 종류·길이와 유출 목록을 점검합니다. 비밀번호는 저장하지 않습니다. 실제 서비스에서도 비밀번호를 바꾼 뒤 끝냅니다. | 다른 계정에 로그인 시도, 생일로 비밀번호 추측 |
| 같은 비밀번호를 쓰던 곳 고르기 | 포털·메신저·쇼핑몰 등 같은 비밀번호를 쓰던 곳을 고르면 그곳에도 로그인 공격을 받을 수 있음을 보여 줍니다. 모두 다른 비밀번호로 바꿨거나 같은 비밀번호를 쓴 곳이 없다고 답합니다. | 다른 계정에 로그인 시도, 같은 아이디의 계정 찾기 |
| 2단계 인증 켜기 | 가상 로그인에서 공격자는 인증번호를 받지 못해 막힙니다. 나는 가상 휴대전화에 온 6자리 번호로 로그인합니다. 체험 뒤 실제 서비스에서도 2단계 인증을 켰다고 답합니다. | 다른 계정에 로그인 시도, 같은 아이디의 계정 찾기, 생일로 비밀번호 추측 |
| 사칭 문자 가려내기 | 내 유출 정보와 관련된 문제부터 3문제를 풉니다. 모두 맞혀야 끝낼 수 있습니다. | 회사 사칭 문자, 이름을 부르는 사기 전화, 회사 공지 사칭 메일, 택배·우편 사칭, 환불을 핑계로 송금 요구 |
| 털린 내 정보 찾기 | 사이트에서 계정 유출을 조회하고 결과를 고릅니다. 유출된 계정이 있다고 고르면 비밀번호 변경과 쓰지 않는 계정 탈퇴를 안내합니다. | 없음. 조회 결과를 저장합니다. |
| 엠세이퍼에서 내 이름을 쓰는지 확인하기 | 사이트에서 내 이름으로 가입된 통신 서비스를 확인하고 결과를 고릅니다. 모르는 가입이 있다고 고르면 통신사 신고와 가입제한 서비스 신청을 안내합니다. | 내 이름으로 가입 시도 |
| 계좌 거래 내역 확인하기 | 은행 앱에서 거래 내역을 확인하고 결과를 고릅니다. 모르는 거래가 있다고 고르면 은행에 지급정지를 요청하고 경찰에 신고하도록 안내합니다. | 없음. 확인 결과를 저장합니다. |
| 개인정보노출자 사고예방시스템에 등록하기 | 사이트를 열어 안내에 따라 등록한 뒤 [등록했습니다]를 누릅니다. | 계좌 개설·대출 시도 |
| 목록에 없는 정보 직접 확인하기 | 무엇을 확인했는지 적고 저장합니다. 내용을 비워 두면 끝낼 수 없습니다. | 없음. 적은 내용을 저장합니다. |

비밀번호 기준은 영문 대문자·소문자, 숫자, 특수문자 중 2종류 이상이면 10자 이상, 3종류 이상이면 8자 이상입니다. 유출 목록을 확인하지 못하면 문자 종류와 길이 기준만으로 판단한다고 안내합니다.

## 파일 구성

| 파일 | 역할 |

| `app.py` | 앱을 실행합니다. 설정을 하고 위쪽 메뉴를 보여 준 뒤 고른 화면을 부릅니다. |

## 코드 구조

프로젝트 파일끼리는 다음 방향으로 부릅니다.

- `app.py`는 화면 파일 다섯 개와 `common.py`, `database.py`, `texts.py`를 부릅니다.
- `screen_intro.py`는 `cases.py`, `common.py`, `database.py`, `stats.py`, `texts.py`를 부릅니다.
- `screen_record.py`는 `cases.py`, `common.py`, `database.py`, `rules.py`, `texts.py`를 부릅니다.
- `screen_todo.py`는 `api.py`, `common.py`, `database.py`, `play.py`, `rules.py`, `screen_missions.py`, `stats.py`, `texts.py`를 부릅니다.
- `screen_missions.py`는 `api.py`, `common.py`, `database.py`, `play.py`, `rules.py`, `screen_play.py`, `texts.py`를 부릅니다.
- `screen_play.py`는 `common.py`, `database.py`, `play.py`, `rules.py`, `texts.py`를 부릅니다. 창을 열고 문자 문제를 함께 쓰는 방향은 `screen_todo.py` → `screen_missions.py` → `screen_play.py`입니다.
- `screen_stats.py`는 `common.py`, `database.py`, `play.py`, `stats.py`, `texts.py`를 부릅니다.
- `common.py`는 `cases.py`, `database.py`, `rules.py`, `stats.py`, `texts.py`를 부릅니다.
- `database.py`는 `rules.py`로 위험 점수와 할 일을 계산한 뒤 저장합니다. `stats.py`도 `rules.py`를 부릅니다.
- `rules.py`는 할 일 이름을 `texts.py`에서 가져옵니다. `api.py`, `cases.py`, `play.py`, `texts.py`는 다른 프로젝트 파일을 부르지 않습니다.

화면을 맡은 함수는 다음과 같습니다.

| 파일 | 함수와 하는 일 |
| --- | --- |
| `app.py` | `show_nav`는 위쪽 메뉴를 보여 줍니다. 파일 아래쪽에서 설정을 하고 고른 화면을 부릅니다. |
| `screen_intro.py` | `show_intro`는 사용 방법, 실제 사례, 체험 안내를 보여 줍니다. |
| `screen_record.py` | `show_record`는 기록하기 화면을 보여 줍니다. `show_paste_box`는 알림문을 붙여넣는 칸, `fill_from_notice`는 유출된 정보를 찾아 고르는 일을 맡습니다. `show_record_form`은 입력 칸을 보여 주고 기록을 저장합니다. |
| `screen_todo.py` | `show_todo`는 할 일 화면, `show_incident_card`는 계기판이 있는 기록 카드를 보여 줍니다. `mission_row`는 할 일 한 줄을 만들고, `show_mission_rows`는 각 줄과 [시작하기]·[결과 보기] 버튼을 보여 줍니다. `show_password_check`는 비밀번호 확인, `show_edit_form`은 기록 수정·삭제 칸을 보여 줍니다. `save_edit`은 수정을 저장하고 `remove_record`는 기록을 지웁니다. |
| `screen_missions.py` | `show_mission`은 해 보기 창을 열고 종류에 맞는 함수를 부릅니다. `mission_password`, `mission_reuse`, `mission_otp`, `mission_quiz`는 차례로 비밀번호 점검, 같은 비밀번호를 쓰던 곳 고르기, 2단계 인증 체험, 사칭 문자 3문제를 맡습니다. `mission_check`는 털린 내 정보 찾기·엠세이퍼·계좌 거래 내역의 확인 결과를 받습니다. `mission_fss`는 사고예방시스템 등록, `mission_note`는 직접 확인한 내용 적기를 맡습니다. `finish_mission`은 끝낸 할 일을 저장하고 창을 닫습니다. `undo_mission`은 남은 일로 되돌려 저장하고, `clear_mission_state`는 창에서 하던 값을 지웁니다. |
| `screen_stats.py` | `show_stats`는 큰 숫자와 막대그래프, 반복 유출 안내, 사칭 문자 가려내기 결과를 보여 줍니다. |
| `screen_play.py` | `show_play`에서 체험을 고릅니다. `show_hacker`는 해커 시점 체험, `show_quiz`는 사칭 문자 가려내기와 결과 저장을 맡습니다. `show_quiz_question`은 문자 문제를 하나씩 보여 주며 체험하기 화면과 할 일 창이 함께 씁니다. `answer_quiz`는 답을 확인하고, `next_quiz`는 다음 문제로 넘기고, `restart_quiz`는 다시 시작합니다. `start_record_from_play`는 고른 정보로 기록하기 화면을 엽니다. |
| `common.py` | `esc`는 입력한 글자를 HTML에 안전하게 넣도록 바꿉니다. `pill`, `risk_pill`, `chips`, `spec_row`는 표시와 정보 줄을 만듭니다. `percent_of`는 비율을 구하고, `progress_bar`, `count_number`, `gauge`는 진행 막대, 움직이는 숫자, 계기판을 만듭니다. `icon`, `verdict`, `stamp`, `phone`은 작은 그림, 결과 띠, 도장, 가상 휴대전화를 만듭니다. `bar_rows`, `repeat_box`, `confetti`는 막대그래프, 반복 유출 경고, 색종이를 만듭니다. `go_to`는 화면을 옮기고 `record_case`는 사례를 기록합니다. `size_text`는 유출 규모를 글자로 바꿉니다. `show_page_head`, `show_empty`, `show_case_card`, `show_case_row`는 제목, 빈 화면 안내, 실제 사례 카드를 보여 줍니다. |

`database.py`는 다음 함수로 기록을 다룹니다.

- `connect_db`는 데이터베이스에 연결합니다. `now_kst`와 `today_kst`는 한국 시간 기준의 현재 시각과 오늘 날짜를 구합니다.
- `create_tables`는 테이블 세 개를 만듭니다. `check_record`는 서비스 이름과 유출된 정보가 있는지, 날짜가 오늘 이후인지 확인합니다.
- `add_record`는 서비스와 유출 기록을 한 번에 저장합니다. 도중에 실패하면 둘 다 저장되지 않습니다. 이름이 같은 서비스가 이미 있으면 대소문자를 구분하지 않고 그 서비스에 기록을 더합니다. `add_case`는 실제 사례를 저장하되 이미 기록한 서비스면 저장하지 않습니다.
- `update_record`는 기록과 서비스의 이름·분류·메모를 고칩니다. 유출된 정보에 맞춰 위험 점수와 할 일을 다시 정합니다. 이름이 같은 할 일은 끝낸 상태와 날짜, 저장된 결과를 그대로 둡니다.
- `delete_record`는 기록을 지웁니다. 그 서비스에 남은 기록이 없으면 서비스도 지웁니다.
- `get_recorded_names`는 기록이 있는 서비스 이름을 가져옵니다. `get_incidents`는 서비스 이름 검색과 할 일 상태로 기록을 조회합니다.
- `save_actions`는 할 일의 끝낸 상태·날짜·결과를 저장합니다. 모든 할 일을 끝냈으면 기록도 완료로 표시합니다. `save_pwned_count`는 비밀번호가 유출 목록에서 발견된 횟수만 저장합니다.
- `add_quiz_result`는 사칭 문자 가려내기 결과를 저장합니다. `get_quiz_summary`는 최고 점수와 푼 횟수를 가져옵니다.

계산과 알림문 찾기는 화면에서 따로 나눴습니다.

- `stats.py`의 `count_remaining`과 `count_all_remaining`은 남은 할 일을 셉니다. 남은 위험 점수는 `rules.py`의 `calc_remaining_score`가 계산합니다. 처음 위험 점수에 남은 할 일의 비율을 곱하고 소수점은 올림합니다. 처음 점수가 0점보다 큰 기록은 할 일을 모두 끝내야 0점이 됩니다.
- `rules.py`의 `find_items_in_text`는 낱말이 들어 있는지 보는 단순한 방법으로 유출된 정보를 찾습니다. “유출되지 않았습니다” 같은 부분과 비밀번호를 바꾸라는 안내, 문의처는 건너뜁니다. 틀릴 수 있어서 찾은 결과를 사용자가 확인하고 고치게 합니다.
- `rules.py`의 `get_mission_type`은 `MISSION_TYPES`에서 할 일에 맞는 창의 종류를 찾습니다. 목록에 없으면 직접 확인한 내용을 적는 창으로 정합니다. `finish_action`은 끝낸 상태·날짜·결과를 넣은 새 할 일 목록을 만들고, `undo_action`은 그 할 일을 다시 남은 일로 바꿉니다.
- `play.py`의 `find_blocked_attacks`는 `MISSION_BLOCKS`에 정한 공격 중 그 기록의 유출 정보로 가능한 것만 찾습니다.

기록 한 건은 다음 순서로 저장됩니다.

1. 기록하기 화면에서 저장 버튼을 누릅니다.
2. `screen_record.py`의 `show_record_form`이 `database.py`의 `add_record`를 부릅니다.
3. `rules.py`가 위험 점수와 할 일을 계산하면 `database.py`가 SQLite에 저장합니다.
4. 저장이 끝나면 할 일 화면으로 이동합니다.

할 일 하나는 다음 순서로 끝냅니다.

1. 할 일 화면에서 [시작하기]를 누릅니다.
2. `screen_todo.py`의 `show_mission_rows`가 `screen_missions.py`의 `show_mission` 해 보기 창을 엽니다.
3. `show_mission`이 할 일 종류에 맞는 함수를 부르면 직접 해 보고 끝내기 버튼을 누릅니다.
4. `finish_mission`이 `rules.py`의 `finish_action`으로 끝낸 상태·날짜·결과를 담고, `database.py`의 `save_actions`로 저장한 뒤 창을 닫습니다.
5. 할 일 화면이 다시 그려집니다. 계기판이 지난번 점수에서 남은 점수까지 움직이고, 방금 끝낸 줄과 막은 공격 표시, 화면 구석 알림이 나타납니다.

## 실행 방법

`app.py`가 있는 폴더에서 다음 명령을 차례로 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

처음 실행하면 기록을 저장할 `leak_ledger.db` 파일이 자동으로 만들어집니다.

테스트는 같은 폴더에서 실행합니다.


## 디자인

화면은 [VESSL Cloud 홈페이지](https://vessl.ai/ko)의 디자인을 따랐습니다. 글자 크기, 색, 카드 모양, 버튼 모양을 재서 같은 값을 썼습니다. VESSL이 파란색을 쓰는 자리에는 유출장부의 민트색을 썼습니다. 파스텔 색은 쓰지 않았습니다.

- 맨 위에는 흰 메뉴 줄이 있습니다. 왼쪽에 로고, 가운데에 화면 이름 다섯 개, 오른쪽에 남색 알약 모양 버튼을 놓았습니다. 화면을 내려도 위에 붙어 있습니다.
- 소개 화면의 머리 구역은 화면 끝까지 민트색으로 채웠습니다. 아래로 갈수록 흰색으로 풀립니다. 그 위에는 80px 굵은 제목과 버튼 두 개가 있습니다.
- 머리 구역 아래쪽에는 실제 유출 사례 카드 세 장을 놓았습니다. 카드에는 이름, 위험 표시, 유출 규모, 유출된 정보, 기록 버튼이 있습니다. VESSL 홈페이지의 GPU 카드와 같은 짜임입니다.
- 그 아래로 사용 방법 세 단계, 큰 숫자 세 개, 앱이 해 주는 일과 하지 않는 일 구역이 이어집니다. 큰 숫자 구역은 회색 바탕이고 나머지는 흰 바탕입니다. 구역 제목은 48px 중간 굵기입니다.
- 카드는 모서리를 24px로 둥글게 하고 안쪽 여백을 24px로 뒀습니다. 그림자는 옅게 넣었습니다.
- 버튼은 모두 알약 모양이고 14px 굵은 글자를 씁니다.
- 소개 화면에는 체험하기를 알리는 남색 구역이 있습니다. 체험하기 화면의 위험 점수 카드도 남색 바탕에 민트색 숫자를 씁니다.
- 공격자가 할 수 있는 일은 아래에서 올라오며 나타납니다. 할 일을 다 끝내면 민트·남색·노랑·빨강 색종이가 떨어집니다. 움직임을 줄이도록 설정한 기기에서는 이 움직임을 보여 주지 않습니다.
- 계기판 바늘은 지난번 점수에서 지금 점수까지 돌며 살짝 지나쳤다 돌아옵니다. 점수가 오르면 계기판이 흔들리고, 내려가면 민트색 빛이 퍼집니다.
- 숫자는 중간 값을 차례로 거치며 나타납니다. 진행 막대도 지난번 값에서 지금 값까지 움직입니다.
- 방금 끝낸 할 일 줄은 한 번 반짝이고, 막은 공격 이름표는 도장처럼 찍힙니다. 다음에 할 일의 버튼은 숨 쉬듯 빛납니다.
- 사칭 문자는 가상 휴대전화에 '입력 중' 점이 보인 뒤 도착합니다. 답하면 문자 위에 정답 도장이 찍히고, 틀리면 휴대전화가 흔들립니다.
- 움직임을 줄이도록 설정한 기기에서는 움직임 없이 마지막 모습만 보입니다.

움직임은 모두 `style.css`가 그립니다. 파이썬은 계기판·숫자·진행 막대의 움직이기 전 값(`--from`)과 뒤 값(`--to`)만 HTML에 적습니다.

## 알아 둘 점

- 위험 점수는 앱이 정한 기준입니다. 공식 위험 등급이 아닙니다.
- 남은 위험 점수도 앱이 정한 기준입니다.
- 알림문에서 유출된 정보를 찾는 기능은 틀릴 수 있으니 결과를 꼭 확인해야 합니다. 붙여넣은 글은 저장하지 않습니다.
- 사칭 문자 가려내기의 문자 예시는 연습용으로 만든 가상 문자입니다. 해커 시점 체험은 널리 알려진 수법을 설명한 것으로, 유출됐다고 반드시 일어나는 일은 아닙니다.
- 비밀번호는 저장하지 않습니다. 알아볼 수 없게 바꾼 값의 앞 5자리만 밖으로 보냅니다.
- 할 일 창의 비밀번호 점검에도 실제로 쓰는 비밀번호 대신 연습용 비밀번호를 넣습니다. 입력한 비밀번호는 저장하지 않습니다.
- 앱은 할 일을 실제로 했는지 확인할 수 없습니다. 사이트에서 확인한 결과나 '켰습니다' 같은 답은 사용자가 고른 것을 그대로 저장합니다.
- 배포된 앱에는 로그인이 없습니다. 모든 방문자가 같은 기록을 함께 보므로 실제 개인정보는 적지 마세요.
- Streamlit Community Cloud에서 앱이 다시 시작되면 기록을 저장한 파일이 지워질 수 있습니다.
- 달력 등 Streamlit이 직접 그리는 일부 글자는 영어로 나옵니다.
