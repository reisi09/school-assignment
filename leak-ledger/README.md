# 유출장부

유출장부는 개인정보 유출 알림을 기록하고, 위험 정도와 할 일을 확인하는 앱입니다. 유출된 정보로 어떤 일이 생길 수 있는지 직접 체험해 볼 수도 있습니다.

고색고 응용 프로그래밍 개발 개인 프로젝트(수행평가 4차)로 만들었습니다.

## 배포 주소

https://reisi09-school-assignment-leak-ledgerapp-leak-ledger-jeudp4.streamlit.app/

| 기록하기 | 받은 유출 알림 문자·메일을 붙여넣으면 유출된 정보를 찾아 골라 줍니다. 직접 적거나 실제 사례를 골라 기록할 수도 있습니다. 위험 점수를 매기는 기준도 확인합니다. |

| 통계 | 기록 수, 남은 위험 점수 합계, 끝낸 할 일 비율을 큰 숫자로 보여 줍니다. 위험 등급별 기록 수와 많이 유출된 정보를 막대그래프로 보여 줍니다. 사칭 문자 가려내기의 최고 점수도 확인합니다. |
| 체험하기 | 해커 시점 체험과 사칭 문자 가려내기 두 가지가 있습니다. 해커 시점 체험은 정보를 누르면 위험 점수가 바로 바뀌고 그 정보로 공격자가 할 수 있는 일이 나타납니다. 사칭 문자 가려내기는 문자 예시 8개를 보고 진짜 안내인지 사칭인지 고릅니다. 내 기록에서 유출된 정보와 관련된 문제가 먼저 나옵니다. |

## 코드 구조

프로젝트 파일끼리는 다음 방향으로 부릅니다.

- `app.py`는 화면 파일 다섯 개와 `common.py`, `database.py`, `texts.py`를 부릅니다.
- 화면 파일은 `common.py`, `database.py`, `rules.py`, `stats.py`, `play.py`, `api.py`, `cases.py`, `texts.py` 중 필요한 것을 부릅니다.
- `common.py`는 `cases.py`, `database.py`, `rules.py`, `stats.py`, `texts.py`를 부릅니다.
- `database.py`는 `rules.py`로 위험 점수와 할 일을 계산한 뒤 저장합니다. `stats.py`도 `rules.py`를 부릅니다.
- `rules.py`는 할 일 이름을 `texts.py`에서 가져옵니다. `api.py`, `cases.py`, `play.py`, `texts.py`는 다른 프로젝트 파일을 부르지 않습니다.

화면을 맡은 함수는 다음과 같습니다.

| 파일 | 함수와 하는 일 |
| --- | --- |
| `app.py` | `show_nav`는 위쪽 메뉴를 보여 줍니다. 파일 아래쪽에서 설정을 하고 고른 화면을 부릅니다. |
| `screen_intro.py` | `show_intro`는 사용 방법, 실제 사례, 체험 안내를 보여 줍니다. |
| `screen_record.py` | `show_record`는 기록하기 화면을 보여 줍니다. `show_paste_box`는 알림문을 붙여넣는 칸, `fill_from_notice`는 유출된 정보를 찾아 고르는 일을 맡습니다. `show_record_form`은 입력 칸을 보여 주고 기록을 저장합니다. |
| `screen_todo.py` | `show_todo`는 할 일 화면, `show_incident_card`는 기록 카드를 보여 줍니다. `save_checked_actions`는 체크한 내용을 저장합니다. `show_password_check`는 비밀번호 확인, `show_edit_form`은 기록 수정·삭제 칸을 보여 줍니다. `save_edit`은 수정을 저장하고 `remove_record`는 기록을 지웁니다. |
| `screen_stats.py` | `show_stats`는 큰 숫자와 막대그래프, 반복 유출 안내, 사칭 문자 가려내기 결과를 보여 줍니다. |
| `screen_play.py` | `show_play`에서 체험을 고릅니다. `show_hacker`는 해커 시점 체험, `show_quiz`는 사칭 문자 가려내기를 보여 줍니다. `start_record_from_play`는 고른 정보로 기록하기 화면을 엽니다. `answer_quiz`는 답을 확인하고, `next_quiz`는 다음 문제로 넘기거나 결과를 저장하고, `restart_quiz`는 다시 시작합니다. |
| `common.py` | `esc`는 입력한 글자를 HTML에 안전하게 넣도록 바꿉니다. `pill`, `risk_pill`, `chips`, `spec_row`, `progress_bar`, `bar_rows`, `repeat_box`, `confetti`는 표시·막대·경고·색종이 같은 화면 조각을 만듭니다. `go_to`는 화면을 옮기고 `record_case`는 사례를 기록합니다. `size_text`는 유출 규모를 글자로 바꿉니다. `show_page_head`, `show_empty`, `show_case_card`, `show_case_row`는 제목, 빈 화면 안내, 실제 사례 카드를 보여 줍니다. |

`database.py`는 다음 함수로 기록을 다룹니다.

- `create_tables`는 테이블 세 개를 만듭니다. `check_record`는 서비스 이름과 유출된 정보가 있는지, 날짜가 오늘 이후인지 확인합니다.
- `add_record`는 서비스와 유출 기록을 한 번에 저장합니다. 도중에 실패하면 둘 다 저장되지 않습니다. 이름이 같은 서비스가 이미 있으면 대소문자를 구분하지 않고 그 서비스에 기록을 더합니다. `add_case`는 실제 사례를 저장하되 이미 기록한 서비스면 저장하지 않습니다.
- `update_record`는 기록을 고칩니다. 유출된 정보에 맞춰 위험 점수와 할 일을 다시 정하고, 이름이 같은 할 일은 끝낸 상태를 그대로 둡니다.
- `delete_record`는 기록을 지웁니다. 그 서비스에 남은 기록이 없으면 서비스도 지웁니다.
- `get_recorded_names`는 기록이 있는 서비스 이름을 가져옵니다. `get_incidents`는 서비스 이름 검색과 할 일 상태로 기록을 조회합니다.
- `save_actions`는 할 일 상태를, `save_pwned_count`는 비밀번호 확인 결과의 횟수를 저장합니다.
- `add_quiz_result`는 사칭 문자 가려내기 결과를 저장합니다. `get_quiz_summary`는 최고 점수와 푼 횟수를 가져옵니다.

계산과 알림문 찾기는 화면에서 따로 나눴습니다.

- `stats.py`의 `count_remaining`과 `count_all_remaining`은 남은 할 일을 셉니다. 남은 위험 점수는 `rules.py`의 `calc_remaining_score`가 계산합니다. 처음 위험 점수에 남은 할 일의 비율을 곱하고 소수점은 올림합니다. 처음 점수가 0점보다 큰 기록은 할 일을 모두 끝내야 0점이 됩니다.
- `rules.py`의 `find_items_in_text`는 낱말이 들어 있는지 보는 단순한 방법으로 유출된 정보를 찾습니다. “유출되지 않았습니다” 같은 부분과 비밀번호를 바꾸라는 안내, 문의처는 건너뜁니다. 틀릴 수 있어서 찾은 결과를 사용자가 확인하고 고치게 합니다.

기록 한 건은 다음 순서로 저장됩니다.

1. 기록하기 화면에서 저장 버튼을 누릅니다.
2. `screen_record.py`의 `show_record_form`이 `database.py`의 `add_record`를 부릅니다.
3. `rules.py`가 위험 점수와 할 일을 계산하면 `database.py`가 SQLite에 저장합니다.
4. 저장이 끝나면 할 일 화면으로 이동합니다.

## 실행 방법

`app.py`가 있는 폴더에서 다음 명령을 차례로 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

처음 실행하면 기록을 저장할 `leak_ledger.db` 파일이 자동으로 만들어집니다.

테스트는 같은 폴더에서 실행합니다.

```bash
python -m unittest -v
```

## 디자인

화면은 [VESSL Cloud 홈페이지](https://vessl.ai/ko)의 디자인을 따랐습니다. 글자 크기, 색, 카드 모양, 버튼 모양을 재서 같은 값을 썼습니다. VESSL이 파란색을 쓰는 자리에는 유출장부의 민트색을 썼습니다. 파스텔 색은 쓰지 않았습니다.

- 맨 위에는 흰 메뉴 줄이 있습니다. 왼쪽에 로고, 가운데에 화면 이름 다섯 개, 오른쪽에 남색 알약 모양 버튼을 놓았습니다. 화면을 내려도 위에 붙어 있습니다.
- 소개 화면의 머리 구역은 화면 끝까지 민트색으로 채웠습니다. 아래로 갈수록 흰색으로 풀립니다. 그 위에는 80px 굵은 제목과 버튼 두 개가 있습니다.
- 머리 구역 아래쪽에는 실제 유출 사례 카드 세 장을 놓았습니다. 카드에는 이름, 위험 표시, 유출 규모, 유출된 정보, 기록 버튼이 있습니다. VESSL 홈페이지의 GPU 카드와 같은 짜임입니다.
- 그 아래로 사용 방법 세 단계, 큰 숫자 세 개, 앱이 해 주는 일과 하지 않는 일 구역이 이어집니다. 큰 숫자 구역은 회색 바탕이고 나머지는 흰 바탕입니다. 구역 제목은 48px 중간 굵기입니다.
- 카드는 모서리를 24px로 둥글게 하고 안쪽 여백을 24px로 뒀습니다. 그림자는 옅게 넣었습니다.
- 버튼은 모두 알약 모양이고 14px 굵은 글자를 씁니다.
- 소개 화면에는 체험하기를 알리는 남색 구역이 있습니다. 체험하기 화면의 위험 점수 카드도 남색 바탕에 민트색 숫자를 씁니다.
- 공격자가 할 수 있는 일은 아래에서 올라오며 나타납니다. 할 일을 다 끝내면 민트·남색·노랑·빨강 색종이가 떨어집니다. 움직임을 줄이도록 설정한 기기에서는 이 움직임을 보여 주지 않습니다.

## 알아 둘 점

- 위험 점수는 앱이 정한 기준입니다. 공식 위험 등급이 아닙니다.
- 남은 위험 점수도 앱이 정한 기준입니다.
- 알림문에서 유출된 정보를 찾는 기능은 틀릴 수 있으니 결과를 꼭 확인해야 합니다. 붙여넣은 글은 저장하지 않습니다.
- 사칭 문자 가려내기의 문자 예시는 연습용으로 만든 가상 문자입니다. 해커 시점 체험은 널리 알려진 수법을 설명한 것으로, 유출됐다고 반드시 일어나는 일은 아닙니다.
- 비밀번호는 저장하지 않습니다. 알아볼 수 없게 바꾼 값의 앞 5자리만 밖으로 보냅니다.
- 배포된 앱에는 로그인이 없습니다. 모든 방문자가 같은 기록을 함께 보므로 실제 개인정보는 적지 마세요.
- Streamlit Community Cloud에서 앱이 다시 시작되면 기록을 저장한 파일이 지워질 수 있습니다.
- 달력 등 Streamlit이 직접 그리는 일부 글자는 영어로 나옵니다.
