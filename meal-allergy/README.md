# 급식 알레르기

학교 급식 식단의 알레르기 번호를 내 알레르기와 비교해 알려 주는 Streamlit 서비스입니다. 고색고 응용 프로그래밍 개발 개인 프로젝트 수행평가로 만들었으며, 이전 학교한눈에서 급식 알레르기 확인에 집중하도록 바꿨습니다.

## 왜 만들었나

식단표는 메뉴 뒤에 `5.6.10.13` 같은 번호로 알레르기 식품을 알려 주므로 번호표를 매번 대조해야 합니다. [KBS 뉴스9의 2026년 7월 24일 보도](https://news.kbs.co.kr/news/view.do?ncd=8619797)에 따르면 식단표에 의무 표기되는 견과류는 땅콩·호두·잣 3종뿐입니다. 같은 보도에서는 지난해 보고된 아나필락시스 환자 1,800여 명의 대다수가 영유아와 10대 청소년이라고 전했습니다. 표시되지 않은 성분까지 알아낼 수는 없지만, 식단에 적힌 번호만이라도 내 알레르기와 쉽게 비교하려고 만들었습니다.

## 등록·조회·검색

| 구분 | 대상 | 사용 방법 |
| --- | --- | --- |
| 등록 | 내 설정: `profiles` | `내 설정`에서 학교·알레르기·이름표를 저장합니다. 같은 이름표로 저장하면 기존 설정을 바꿉니다. |
| 등록 | 급식 기록: `meals` | `찾기`에서 검색하면 오늘 앞뒤 28일의 급식을 받아 메뉴 한 줄씩 저장합니다. 같은 학교·날짜·끼니·메뉴는 중복으로 남기지 않습니다. |
| 조회 | 저장한 설정 | 이름표로 학교와 알레르기를 불러옵니다. |
| 조회 | 급식과 알레르기 표시 | `오늘`과 `급식표`에서 오늘·이번 주 급식을 보고 내 알레르기 번호가 표시된 메뉴를 확인합니다. |
| 검색 | 급식 기록 | `메뉴 이름`·`알레르기 식품` 조건으로 `meals`를 SQL 검색합니다. 둘 다 고르면 두 조건에 모두 맞는 메뉴만 찾습니다. 메뉴 이름은 띄어쓰기를 빼고 비교합니다. |
| 검색 | 학교 | `내 설정`의 `학교 찾기`에서 학교 이름으로 찾습니다. 결과에는 학교 이름과 주소를 함께 표시합니다. |

급식 검색은 현재 선택한 학교의 저장된 기록 전체를 대상으로 합니다. 예전에 저장한 기록은 오늘 앞뒤 28일을 벗어나도 검색하며, 최근 날짜부터 보여 줍니다. 나이스 연결에 실패해도 이미 저장된 기록에서는 검색합니다. `오늘`과 `급식표`를 보는 것만으로는 급식 기록을 DB에 저장하지 않습니다.

## 알레르기를 알아내는 방법

나이스의 메뉴 글자는 `<br/>`로 이어져 있습니다. `foods.py`의 `parse_dishes`가 줄을 나누고, `parse_dish`가 각 줄 끝의 숫자 괄호를 메뉴 이름과 분리합니다. 이름 안의 `(수제)` 같은 괄호는 남깁니다.

```python
from foods import find_my_allergens, parse_dish

parse_dish("돈육한방수육 (5.6.10.13)")
# ("돈육한방수육", [5, 6, 10, 13])

parse_dish("김치함박스테이크(수제) (2.5.6)")
# ("김치함박스테이크(수제)", [2, 5, 6])

find_my_allergens([5, 6, 10, 13], [10, 5])
# ["대두", "돼지고기"]
```

`find_my_allergens`는 메뉴 번호와 내 알레르기 번호가 겹치는 식품의 이름을 돌려줍니다. `screen_meal.py`의 `dishes_html`은 해당 메뉴를 빨갛게 표시하고 식품 이름을 붙입니다. `count_risky_dishes`는 해당 메뉴 수를 셉니다.

번호와 식품 이름은 `foods.py`의 `ALLERGENS`에 다음과 같이 들어 있습니다.

| 번호 | 식품 | 번호 | 식품 |
| --- | --- | --- | --- |
| 1 | 난류 | 11 | 복숭아 |
| 2 | 우유 | 12 | 토마토 |
| 3 | 메밀 | 13 | 아황산류 |
| 4 | 땅콩 | 14 | 호두 |
| 5 | 대두 | 15 | 닭고기 |
| 6 | 밀 | 16 | 쇠고기 |
| 7 | 고등어 | 17 | 오징어 |
| 8 | 게 | 18 | 조개류 |
| 9 | 새우 | 19 | 잣 |
| 10 | 돼지고기 | — | — |

학교가 식단에 표시한 번호만 비교합니다. 표시되지 않은 성분·교차오염·개인별 민감도는 알 수 없습니다. `내 알레르기 메뉴 없음`도 안전하게 먹어도 된다는 뜻은 아닙니다. 참고용이며 의학적 판단을 대신하지 않으므로 먹기 전에 영양 선생님께 확인해야 합니다.

## 쓴 자료 (API)

학교 자료는 [나이스 교육정보 개방 포털](https://open.neis.go.kr)의 공개 API에서 받습니다. `neis.py`의 요청 주소는 `https://open.neis.go.kr/hub/`입니다.

| 자료 | API 이름 | 앱에서 쓰는 내용 |
| --- | --- | --- |
| 학교 기본 정보 | `schoolInfo` | 학교 이름·종류·교육청 코드·학교 코드·주소로 학교를 찾습니다. |
| 급식 | `mealServiceDietInfo` | 날짜·끼니·메뉴·알레르기 번호·열량·영양 정보·원산지·급식 인원을 받습니다. |
| 학사일정 | `SchoolSchedule` | 급식이 없는 날에 휴업일·공휴일의 행사 이름을 보여 줍니다. |

인증키 없이도 모든 기능을 사용할 수 있습니다. 다만 키가 없으면 한 번에 5건까지만 받습니다. `fetch_range`는 전체 기간을 먼저 요청하고, 덜 받으면 일주일씩 나눠 요청합니다. 그래도 다 받지 못한 주는 하루씩 나눠 받습니다.

학교 검색은 기간을 나눌 수 없으므로 키가 없으면 앞 5곳만 보여 줍니다. 결과가 더 많으면 학교 이름을 자세히 쓰라는 안내가 나옵니다. 하루 자료 자체가 5건을 넘는 경우에도 키 없이 전부 받는 것은 보장하지 않습니다.

`search_schools`, `fetch_meals`, `fetch_schedule`은 `st.cache_data(ttl=3600)`으로 받은 자료를 1시간 기억합니다. 같은 조건으로 다시 조회할 때는 저장해 둔 응답을 씁니다. 이 임시 저장과 SQLite의 급식 기록 저장은 별개입니다.

## 나이스 인증키(선택)

인증키를 넣으면 한 번에 최대 1,000건을 요청하므로 기간을 나눠 요청하는 횟수가 줄어듭니다. 나이스 교육정보 개방 포털에서 인증키를 발급받습니다.

로컬에서는 `app.py`가 있는 폴더 아래에 `.streamlit/secrets.toml`을 만들고 다음 줄을 넣습니다.

```toml
NEIS_KEY = "발급받은 키"
```

Streamlit Community Cloud에서는 앱의 Settings → Secrets에 같은 줄을 넣습니다. `.streamlit/secrets.toml`은 `.gitignore`에 있어 git에 올라가지 않습니다. 인증키는 코드에 적지 않습니다.

| `screen_today.py` | → `common.py`, `days.py`, `foods.py`, `neis.py`, `screen_meal.py`, `screen_settings.py`, `texts.py` |
| `screen_meal.py` | → `common.py`, `days.py`, `foods.py`, `neis.py`, `texts.py` |

| `neis.py` | → `days.py` |
| `database.py` | → `days.py`, `foods.py` |

`app.py`는 `show_nav`에서 고른 메뉴에 맞는 화면 함수를 부릅니다. 화면은 `neis.py`에서 공개 자료를 받고, 설정 저장과 급식 검색에는 `database.py`를 씁니다. `foods.py`와 `days.py`는 글자와 날짜 계산을 맡습니다.

### 저장하는 자료와 함수

`connect_db`는 같은 폴더의 `meal_allergy.db`에 연결합니다. `create_tables`는 `profiles`와 `meals`를 만들며, 이미 있으면 그대로 둡니다. 두 테이블에는 각각 9개와 7개, 모두 16개의 칸이 있습니다.

| 테이블 | 칸 이름 | 저장하는 내용 |
| --- | --- | --- |
| `profiles` | `id` | 자동으로 붙는 고유 번호 |
| `profiles` | `nickname` | 중복되지 않는 이름표 |
| `profiles` | `school_name` | 학교 이름 |
| `profiles` | `school_kind` | 학교 종류 |
| `profiles` | `atpt_code` | 교육청 코드 |
| `profiles` | `school_code` | 학교 코드 |
| `profiles` | `allergies` | 쉼표로 이은 알레르기 번호. 예: `5,10` |
| `profiles` | `created_at` | 처음 저장한 시각 |
| `profiles` | `updated_at` | 마지막으로 저장한 시각 |
| `meals` | `id` | 자동으로 붙는 고유 번호 |
| `meals` | `school_code` | 학교 코드 |
| `meals` | `meal_date` | 급식 날짜. 예: `2026-11-17` |
| `meals` | `meal_name` | 끼니 이름. 예: 중식 |
| `meals` | `dish` | 메뉴 이름 |
| `meals` | `allergy_codes` | 앞뒤를 쉼표로 감싼 알레르기 번호. 예: `,5,6,10,13,`. 번호가 없으면 빈 글자 |
| `meals` | `saved_at` | 급식 기록을 저장한 시각 |

| 함수 | 하는 일 |
| --- | --- |
| `connect_db` | SQLite에 연결하고 칸 이름으로 값을 읽도록 정합니다. |
| `create_tables` | 두 테이블을 준비합니다. |
| `save_profile` | 이름표로 설정을 저장하거나 바꿉니다. 이름표가 비면 저장하지 않으며, 수정할 때도 `created_at`은 유지합니다. |
| `load_profile` | 이름표로 설정을 읽습니다. 없으면 `None`을 돌려줍니다. |
| `save_meals` | 받은 급식을 메뉴별로 저장합니다. 같은 `school_code`·`meal_date`·`meal_name`·`dish`는 `INSERT OR REPLACE`로 바꿔 씁니다. |
| `search_meals` | 학교 코드·메뉴 이름·알레르기 번호로 SQL 검색하고 최근 날짜부터 돌려줍니다. |
| `count_meals` | 해당 학교에 저장된 메뉴 기록 수를 셉니다. |

`allergy_codes`의 앞뒤에 쉼표를 붙이는 이유는 번호를 정확히 구분하려는 것입니다. 5번을 `LIKE '%,5,%'`로 찾으면 15번인 `,15,`는 검색되지 않습니다. `search_meals`는 검색값을 SQL의 `?` 자리에 따로 전달합니다.

DB에는 내 설정과 메뉴 검색에 필요한 급식 기록만 저장합니다. 열량·영양 정보·원산지·학사일정은 이 테이블에 저장하지 않습니다.

### 내 설정을 유지하는 방법

`screen_settings.py`의 `use_profile`은 설정을 `st.session_state["profile"]`에 넣고 `st.query_params["me"]`에 이름표를 넣습니다. 주소창에는 `?me=이름표`가 남습니다.

새로고침하거나 그 주소를 다시 열면 `app.py`가 이름표를 읽어 `load_profile`로 설정을 불러옵니다. 현재 세션에 설정이 없을 때만 불러오며, DB에 해당 이름표가 있어야 합니다. 주소에는 설정 전체가 아니라 이름표만 들어갑니다. 로그인이나 비밀번호는 아닙니다.

## 실행 방법

`app.py`가 있는 폴더에서 다음 명령을 차례로 입력합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

DB 파일 `meal_allergy.db`는 처음 실행할 때 같은 폴더에 자동으로 만들어집니다.

테스트 명령은 다음과 같습니다.

```bash
python -m unittest -v
```

`test_meal_allergy.py`에는 테스트가 12개 있습니다.

| 구분 | 개수 | 확인하는 내용 |
| --- | --- | --- |
| `FoodsTest` | 4 | 메뉴 이름과 번호 분리, 전체 메뉴 줄 나누기, 영양 정보·열량 읽기, 내 알레르기 비교와 메뉴 수 계산 |

## 알아 둘 점

- 로그인이 없어 이름표를 아는 사람은 누구나 설정을 불러올 수 있습니다. 같은 이름표로 저장하면 다른 사람의 설정도 바뀝니다. 알레르기는 건강 정보이므로 실명이나 개인을 알아볼 수 있는 정보는 쓰지 않습니다.
- Streamlit Community Cloud에서 앱이 다시 시작되면 DB가 지워질 수 있습니다. 저장한 설정과 급식 기록이 계속 남는다고 보장하지 않습니다.
- `screen_meal.py`의 `empty_message`는 급식 자료가 없는 날짜가 오늘보다 뒤이고 학사일정의 쉬는 날 목록에도 없으면 `급식 자료 미등록`을 돌려줍니다. 그 밖에는 `급식 없음`을 돌려줍니다. 주간 화면은 월요일부터 금요일까지만 보여 주며, 쉬는 날 이름이 있으면 함께 표시합니다. 이 문구는 날짜와 학사일정으로 구분한 것이므로 실제 미등록 사유를 확인한 결과는 아닙니다.
- 오늘 급식 카드에 자료가 없으면 `오늘 급식 자료가 없습니다.`로 표시합니다. 나이스 요청에 실패하면 연결 오류 안내도 나옵니다.
- 달력 등 Streamlit 기본 요소의 일부 글자는 영어로 나올 수 있습니다. 이 앱에는 별도의 달력 입력 기능이 없습니다.
- Streamlit의 HTML 안 SVG 제거와 CSS 안 꺾쇠 처리 문제를 피하려고 로고는 CSS로 그렸습니다. `style.css`의 `.brand-mark`에서 달력 모양을 만듭니다.
